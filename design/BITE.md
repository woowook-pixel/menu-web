# Bite 적용 기준

공통 기준은 `DESIGN.md`, 토큰은 `tokens.css`를 따른다. 이 문서는 Bite(구 오늘 뭐 먹지)에만 해당하는 내용이다.

## 앱 이름

- 표시 이름: "오늘 뭐 먹지" → `Bite`
- 상단 바 워드마크: `BITE`
- HTML `<title>`, manifest(있다면) `name`, `short_name`도 Bite로 변경

## 메뉴 데이터 처리 원칙

- 메뉴가 이미지(식단표 사진)로만 제공된다면, 이미지를 그대로 크게 보여준다. 이미지 속 메뉴를 텍스트로 뽑아내는 기능(OCR 등)은 만들지 않는다.
- 메뉴가 이미 텍스트 데이터로 있다면, 섹션 라벨 "주메뉴", "반찬" + 목록 행으로 보여준다.
- 메뉴 이미지는 흑백 처리하지 않는다. 음식 사진이자 메뉴 정보이므로 원본 색을 유지한다(공통 기준의 흑백 사진 원칙에서 Bite만 예외).
- 이미지는 모서리 없이 화면 좌우 여백 안에서 전체 폭으로 보여준다.

## 화면별 변경

### 오늘 (탭 1)

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 | 없음 | 상단 바: 왼쪽 `BITE`, 오른쪽 텍스트 버튼 "이번 주 →" (이번 주 탭으로 이동) |
| 날짜 | 빨간 "10월 12일 월요일" | 제목 위 보조 라벨: Ember 점 + 날짜 |
| 제목 | "오늘의 메뉴" | 44px 900 제목 |
| 메뉴 | 둥근 모서리 이미지, 왼쪽 주황 테두리 | 모서리 없는 이미지, 테두리 없음 (텍스트 데이터가 있으면 아래에 목록) |
| 탭바 | 아이콘 + 글자, 빨간 활성 | 글자만: 오늘 / 이번 주 |

### 이번 주 (탭 2)

| 영역 | 현재 | 변경 |
|---|---|---|
| 상단 | 빨간 "이번 주" + 큰 "10월" + 회색 화살표 | 상단 바: 왼쪽 `BITE`, 오른쪽 텍스트 버튼 "←", "→" (이전·다음 주) |
| 제목 | "10월" | 보조 라벨 "이번 주" + 44px 제목 "10월" |
| 요일 선택 | 흰 카드 안 요일, 빨간 원 날짜, 썸네일 5개 | 밑줄 탭: 월 12 / 화 13 / 수 14 / 목 15 / 금 16. 오늘 날짜 탭에 Ember 점, 선택한 날은 검정 2px 밑줄. 썸네일 줄 제거 |
| 선택한 날 | "10월 12일 월요일" + 빨간 "오늘" 배지 | 섹션 라벨 "10월 12일 월요일", 오늘이면 오른쪽에 Ember 점 + "오늘" |
| 메뉴 | 큰 둥근 이미지 | 선택한 날의 메뉴 이미지, 오늘 탭과 같은 방식 |
| 탭바 | 아이콘 + 글자, 빨간 활성 | 글자만: 오늘 / 이번 주 |

### 메뉴가 없는 날 (주말, 휴일, 미등록)

- 검은 1px 선 아래 30px 900 "메뉴가 없습니다." + Gray 안내문(기존 문구가 있으면 그대로).

## Ember 사용 위치 (Bite)

- 오늘 날짜 표시(오늘 탭의 날짜 라벨, 이번 주 탭의 오늘 요일과 "오늘" 표시). 모두 "오늘"이라는 한 가지 의미로만 쓴다.

## 하지 말 것

- 메뉴를 가져오는 방식, 날짜 계산, 이미지 로딩 로직은 건드리지 않는다.
- 빨간색(기존 강조색)을 다른 곳에 남기지 않는다.
