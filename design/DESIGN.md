# Personal App Family 디자인 기준 v1

대상 앱: Bite, Script, Wayly, Lexi, Pitch, Fret
공통 토큰: `tokens.css` (이 파일과 같은 폴더)

## 1. 원칙

- 흑백 기반. 박스와 카드 대신 여백, 큰 글자, 가는 선으로 구조를 만든다.
- 모서리 없음(radius 0). 원형 버튼, 알약형 칩, 그림자를 쓰지 않는다.
- 아이콘 버튼 대신 텍스트 버튼을 쓴다(예: "← →", "+ 추가", "설정", "닫기").
- Ember(#FF7A3D)는 "지금, 오늘, 현재 상태"를 가리킬 때만 쓴다. 장식에 쓰지 않는다.
- 정보 색은 예외로 허용한다(Wayly 버스 노선 빨강). 숫자나 글자 색으로만 쓰고 면을 채우지 않는다.
- 사진은 흑백 처리(`filter: grayscale(1)`)를 기본으로 한다.
- 라이트 모드만 정의되어 있다. 다크 모드는 미정이며 임의로 만들지 않는다.

## 2. 색

| 이름 | 값 | 용도 |
|---|---|---|
| Black | #111111 | 글자, 주 버튼, 섹션 시작선, 아이콘 바탕 |
| White | #FFFFFF | 화면 바탕 |
| Gray | #6E6E6E | 보조 텍스트 |
| Mute | #9A9A9A | 비활성 탭 |
| Line | #E6E6E6 | 목록 구분선 |
| Ember | #FF7A3D | 지금·오늘·현재 표시 전용 |
| Info Red | #D7262E | 정보 색 예외 |

## 3. 글자

폰트: Archivo(라틴) + Noto Sans KR(한글). 로드 링크는 `tokens.css` 상단 주석 참조.
고정폭 예외: 타브 악보처럼 글자 칸 정렬이 필요한 곳만 IBM Plex Mono(`--pf-mono`)를 쓴다.

| 역할 | 크기/굵기 | 비고 |
|---|---|---|
| 워드마크 | 15 / 900 | 대문자, 자간 0.14em |
| 화면 제목 | 44 / 900 | 자간 -0.035em, 필요하면 두 줄 |
| 시트·빈 상태 제목 | 30 / 900 | |
| 본문 | 16 / 500 | |
| 보조 | 12 / 400 | Gray |
| 섹션 라벨 | 11 / 800 | 자간 0.12em |
| 텍스트 버튼 | 12 / 700 | 자간 0.08em |

## 4. 화면 골격 (모든 화면 공통 순서)

1. 상단 바: 왼쪽 대문자 앱 이름, 오른쪽 텍스트 버튼 최대 2개
2. 제목 블록: 보조 라벨(선택, Ember 점 가능) + 44px 제목
3. 밑줄 탭: 필터, 모드, 날짜, 줄 선택 등 모든 전환을 이 하나로 처리
4. 섹션 라벨 + 목록: 목록 시작은 검은 1px 선, 행 구분은 Line 색 1px 선
5. 주 버튼(필요할 때만): 전체 폭 검정 바, 높이 56px
6. 하단 탭바: 글자만, 현재 탭은 검정 굵게, 나머지 Mute

## 5. 부품

| 부품 | 클래스 | 규칙 |
|---|---|---|
| 상단 바 | `.pf-topbar` `.pf-wordmark` `.pf-action` | 아이콘 버튼 금지 |
| 제목 | `.pf-titleblock` `.pf-eyebrow` `.pf-title` | |
| 현재 표시 | `.pf-now` | 7px Ember 사각 점 |
| 탭 | `.pf-tabs` `.pf-tab[aria-selected]` | 선택은 검정 2px 밑줄 |
| 목록 | `.pf-label` `.pf-list` `.pf-row` | 행 최소 높이 52px |
| 주 버튼 | `.pf-btn-primary` | 화면당 1개 |
| 입력 | `.pf-input` | 밑줄형, 테두리 박스 금지 |
| 탭바 | `.pf-tabbar` | 아이콘 없음 |
| 시트 | `.pf-sheet` | 상단 직선 + 검정 2px 선, 뒤 배경 `--pf-dim` |

빈 상태: 검은 선 아래 30px 제목("아직 없습니다.") + Gray 안내문 + 밑줄형 텍스트 버튼.

## 6. 앱 아이콘

- 파일: `icons/<app>.svg` 및 180, 192, 512, 1024 PNG
- 검정 바탕, 흰 글리프 65%, Ember는 글리프 안 한 곳
- iOS 홈 화면: `apple-touch-icon` 180px, PWA manifest: 192, 512px

## 7. 앱 이름

Bite(구 오늘 뭐 먹지), Script(구 On Air), Wayly, Lexi(구 사전), Pitch(구 튜너), Fret(구 타브 리더)

## 8. 금지 목록

- border-radius, 원형 요소, box-shadow 그림자(선 표현용 inset 1-2px 제외)
- 그라데이션, 보라·파랑 등 기존 앱 색
- 카드 배경 면, 회색 박스 입력창
- Ember를 버튼 배경, 제목 색, 장식에 사용
