- 내용:
  1. 상단 바를 `DESIGN.md` 10장 구조(`.pf-header > .pf-topbar`)로 바꾼다.
  2. 앱이 직접 준 화면 위 여백(padding-top, margin-top, safe-area 계산, 고정 54px 등)을 모두 지운다. 위치는 `.pf-header`가 맡는다.

## 006 (2026-10-12) 홈 아이콘 회색 글자 타일 수정

- 대상: 전체
- 원인: iOS가 apple-touch-icon 파일 요청만 실패(정확한 원인 미확인). 경로, 캐시, 배포 보호, 서비스 워커, 메타데이터는 원인 아님.
- 해결: apple-touch-icon만 data 주소로 HTML에 직접 넣는다. favicon과 manifest는 중앙 파일 주소 유지.
- 주의: 아이콘 이미지를 바꾸면 data 주소도 다시 만들어야 한다(이 저장소에서 만들어 프롬프트로 전달).

## 007 (2026-10-12) 공통 파일 자동 복사 방식으로 전환

- 대상: 전체
- 이유: 개발 세션이 중앙 주소에 접속하지 못해 화면 확인이 안 되고, 실행 중 다른 도메인 의존으로 iOS 아이콘 문제와 단일 장애점이 생김.
- 내용: personal-design에 커밋하면 GitHub Actions(sync-shared)가 각 앱의 design/shared/로 복사하는 PR을 연다. 앱은 같은 도메인의 복사본만 쓴다. 적용 프롬프트는 prompts/migrate-local.md.
- 이후 운영: CSS·기호·아이콘 변경은 personal-design 커밋 → 자동 PR 합치기. 구조 변경만 CHANGELOG + 붙여 넣기 프롬프트.

## 010 (2026-10-13) tokens.css에서 상대 경로 이미지 참조 제거

- 대상: 전체 (공통 CSS만 변경)
- 이유: 쓰지 않는 예전 기호 규칙(`.pf-sym-*`, mask 이미지 `url("symbols/...")`)이 남아 있어, 빌드형 앱이 tokens.css를 import하면 경로를 찾지 못해 link로 예외 처리해야 했음.

- 앱 작업: link로 예외 처리했던 앱은 원하면 import로 되돌려도 된다(필수 아님).
