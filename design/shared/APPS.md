# 앱 목록과 앱별 예외

패밀리 공통 기준(`DESIGN.md`)을 벗어나는 부분은 이 표에 있는 것만 허용한다.

| 앱 | 구 이름 | 하단 탭 | Ember 위치 | 공통 기준 예외 |
|---|---|---|---|---|
| Bite | 오늘 뭐 먹지 | 오늘 / 이번 주 | 오늘 날짜, 오늘 요일 | 메뉴 이미지 컬러 유지 |
| Script | On Air | 듣기 / 읽기 / 보관함 | 지금 재생 중(미니 플레이어, 진행 위치) | 없음 |
| Wayly | Wayly | 내 경로 / 길찾기 / 지도 / 더보기 | 실시간 업데이트 표시 | 버스 노선 Info Red 글자 |
| Lexi | 영한/한영 사전 | 검색 / 즐겨찾기 | 표제어 형광펜 밑줄 | 없음 |
| Pitch | 튜너 | 없음(설정은 시트) | 현재 음정 막대, 자동 감지 표시 | 정확 상태는 음 이름 글자 검정 |
| Strum | 타브 리더 | 없음 | (UI 미적용, 아이콘만) | 이름·아이콘만 패밀리 적용 |
| Riff | 없음(신규, 저장소 song-builder) | 없음(하단은 재생 바: 재생, 처음으로, 구간 반복, 메트로놈, 곡 지도) | 재생 위치(편곡 화면의 세로 재생선, 지금 재생 중인 마디 표시) | 없음 |

## 아이콘 글리프

| 앱 | 글리프 | Ember 부분 |
|---|---|---|
| Bite | 김 오르는 밥그릇 | 젓가락 |
| Script | 펼친 책 + 소리 파동 | 책갈피 끈 |
| Wayly | 버스 정면 | 헤드라이트 |
| Lexi | A가 | 형광펜 밑줄 |
| Pitch | 튜너 눈금 | 가로 기준 막대 |
| Strum | 기타 피크 + 타브 줄 세 개 | 가운데 줄 사각 |
| Riff | 계단처럼 쌓이는 가로 막대 세 개 | 맨 위 막대 |

## 새 앱을 패밀리에 넣을 때

1. 영문 한 단어 이름(어미 맞추기 없음)
2. 검정 바탕 + 흰 글리프 65% + Ember 한 곳
3. 화면은 `DESIGN.md` 4장 골격 순서대로
4. 예외가 필요하면 이 표에 먼저 추가하고 나서 적용
