# Personal App Family 디자인 기준 v1

대상 앱: Bite, Script, Wayly, Lexi, Pitch, Strum
공통 토큰: `v1/tokens.css` (이 파일과 같은 폴더)

## 1. 원칙

- 흑백 기반. 박스와 카드 대신 여백, 큰 글자, 가는 선으로 구조를 만든다.
- 모서리 없음(radius 0). 원형 버튼, 알약형 칩, 그림자를 쓰지 않는다.
- 아이콘 버튼 대신 텍스트 버튼을 쓴다(예: "← →", "+ 추가", "설정", "닫기").
- Ember(#FF7A3D)는 "지금, 오늘, 현재 상태"를 가리킬 때만 쓴다. 장식에 쓰지 않는다.
- 정보 색은 예외로 허용한다(Wayly 버스 노선 빨강). 숫자나 글자 색으로만 쓰고 면을 채우지 않는다.
- 사진은 흑백 처리(`filter: grayscale(1)`)를 기본으로 한다.
- 라이트 모드만 정의되어 있다. 다크 모드는 미정이며 임의로 만들지 않는다.

## 2. 색

| 이름 | 값 | 용도 |
|---|---|---|
| Black | #111111 | 글자, 주 버튼, 섹션 시작선, 아이콘 바탕 |
| White | #FFFFFF | 화면 바탕 |
| Gray | #6E6E6E | 보조 텍스트 |
| Mute | #9A9A9A | 비활성 탭 |
| Line | #E6E6E6 | 목록 구분선 |
| Ember | #FF7A3D | 지금·오늘·현재 표시 전용 |
| Info Red | #D7262E | 정보 색 예외 |

폰트: Archivo(라틴) + Noto Sans KR(한글). 로드 링크는 `v1/tokens.css` 상단 주석 참조.
고정폭 예외: 타브 악보처럼 글자 칸 정렬이 필요한 곳만 IBM Plex Mono(`--pf-mono`)를 쓴다.

## 4. 화면 골격 (모든 화면 공통 순서)

1. 상단 바: 왼쪽 대문자 앱 이름, 오른쪽 텍스트 버튼 최대 2개
2. 제목 블록: 보조 라벨(선택, Ember 점 가능) + 44px 제목
3. 밑줄 탭: 필터, 모드, 날짜, 줄 선택 등 모든 전환을 이 하나로 처리
4. 섹션 라벨 + 목록: 목록 시작은 검은 1px 선, 행 구분은 Line 색 1px 선
5. 주 버튼(필요할 때만): 전체 폭 검정 바, 높이 56px
6. 하단 탭바: 글자만, 현재 탭은 검정 굵게, 나머지 Mute

## 5. 부품

| 부품 | 클래스 | 규칙 |
|---|---|---|
| 상단 바 | `.pf-topbar` `.pf-wordmark` `.pf-action` | 아이콘 버튼 금지 |
| 제목 | `.pf-titleblock` `.pf-eyebrow` `.pf-title` | |
| 현재 표시 | `.pf-now` | 7px Ember 사각 점 |
| 탭 | `.pf-tabs` `.pf-tab[aria-selected]` | 선택은 검정 2px 밑줄 |
| 목록 | `.pf-label` `.pf-list` `.pf-row` | 행 최소 높이 52px |
| 주 버튼 | `.pf-btn-primary` | 화면당 1개 |
| 입력 | `.pf-input` | 밑줄형, 테두리 박스 금지 |
| 탭바 | `.pf-tabbar` | 아이콘 없음 |
| 시트 | `.pf-sheet` | 상단 직선 + 검정 2px 선, 뒤 배경 `--pf-dim` |

빈 상태: 검은 선 아래 30px 제목("아직 없습니다.") + Gray 안내문 + 밑줄형 텍스트 버튼.

## 6. 앱 아이콘

- 파일: `icons/<app>.svg` 및 180, 192, 512, 1024 PNG
- 검정 바탕, 흰 글리프 65%, Ember는 글리프 안 한 곳
- iOS 홈 화면: `apple-touch-icon` 180px, PWA manifest: 192, 512px

## 7. 앱 이름

Bite(구 오늘 뭐 먹지), Script(구 On Air), Wayly, Lexi(구 사전), Pitch(구 튜너), Strum(구 타브 리더, 이름·아이콘만 적용)

## 8. 금지 목록

- border-radius, 원형 요소, box-shadow 그림자(선 표현용 inset 1-2px 제외)
- 그라데이션, 보라·파랑 등 기존 앱 색
- 카드 배경 면, 회색 박스 입력창
- Ember를 버튼 배경, 제목 색, 장식에 사용

## 9. 배치 규칙

- 상단 바 왼쪽: 최상위 화면은 대문자 앱 이름. 하위 화면(상세, 재생, 편집)은 앱 이름 대신 "← 상위 화면 이름".
- 상단 바 오른쪽: 텍스트 버튼 최대 2개. 가장 오른쪽(바깥쪽)에 주 동작, 안쪽에 보조 동작. 예: "편집  + 추가".
- 시트: 제목 오른쪽에 "닫기". 확정 동작은 시트 맨 아래 주 버튼 하나.
- 하단: 위에서부터 미니 플레이어 등 고정 바 → 탭바 순서. 화면 내용은 두 바에 가리지 않게 아래 여백을 둔다.
- 주 버튼은 화면당 하나, 내용 맨 아래에 둔다.

## 10. 상단 헤더 규격 (CHANGELOG 002)

- 모든 화면의 상단 바는 `.pf-header` 안의 `.pf-topbar`로 만든다. 구조: `.pf-header > .pf-topbar > (.pf-wordmark 또는 "← 상위 화면", .pf-actions > .pf-action)`
- 시작 위치: 기기 상단 안전 영역 바로 아래. 앱이 따로 위 여백(54px, safe-area 등)을 주지 않는다.
- 높이: 44px. 스크롤해도 위에 고정, 흰 바탕.
- 워드마크: `.pf-wordmark`만 사용, 앱별 크기 지정 금지.
- 오른쪽 버튼: `.pf-actions` 안에 두고 간격 20px, 마지막 버튼 글자 끝이 화면 오른쪽 여백선(20px)에 맞는다.
- 헤더와 제목 블록 사이: 24px.
- 탭바 글자는 각 칸 가운데 정렬.

## 11. 아이콘과 기호

- 홈 아이콘: 검정 바탕 + 흰 곡선 글리프 65% + Ember 한 곳. 원본은 `icons/<앱이름>.svg`와 PNG. iOS용 apple-touch-icon만 data 주소로 HTML에 직접 넣는다(CHANGELOG 006). 픽셀 버전(`icons/pixel/`)은 보관용으로만 둔다.
- 기호: 24 격자, 선 굵기 2.6, 끝과 모서리 각지게. 꽉 찬 도형은 재생, 정지, 더보기만. 색은 글자색을 따른다. 중앙 `v1/symbols.js`의 `<pf-sym name="...">` 요소로 쓴다. 제목, 섹션 라벨, 본문에는 넣지 않는다.

## 12. 새 버전 알림

- 탭바 위 검정 띠(`.pf-update`). 문구 "새 버전이 있습니다", 버튼 "나중에", "새로고침". Ember 점은 CSS가 자동으로 붙인다.
- 탭바가 없는 화면은 `.pf-no-tabbar`를 붙여 하단 안전 영역 위에 띄운다.

## 13. 앱 캐릭터

- 앱마다 하나: Bite 주먹밥, Script 라디오, Wayly 버스 옆모습, Lexi 돋보기, Pitch 반원 튜너 게이지, Strum 기타, Riff 쌓이는 막대. 높이 14칸 픽셀, 가로 길이는 캐릭터마다 다름, 컬러, 4프레임 GIF.
- 쓰는 곳: 최상위 화면 상단 바의 워드마크 오른쪽 한 곳. 높이 28px(픽셀 2배), 가로는 비율대로(`.pf-brand-character`). 하위 화면에는 넣지 않는다.
- 움직임 줄이기 설정이면 정지 이미지(-still.png).
- 장식이므로 alt는 비운다.
